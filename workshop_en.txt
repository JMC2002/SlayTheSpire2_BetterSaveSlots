[h1]Better Save Slots (Fixes Missing Modded Saves)[/h1]
[h2] 1. Overview [/h2]
Lost your saves after installing mods? Want to test mods temporarily without risking your saves? Are three save slots not enough? Use this mod to solve it!

[url=https://github.com/JMC2002/SlayTheSpire2_BetterSaveSlots] GitHub Repository [/url]
[url=https://www.bilibili.com/video/BV1FoJ56FEgr/] Demo Video (Bilibili) [/url]

[h2] 2. Features [/h2]
[list]
    [*] Adds copy/paste buttons to each slot on the save selection screen, with a confirmation popup before overwriting an existing save
    [img]https://images.steamusercontent.com/ugc/12505392034722102489/7374D0BDCB4E67BA5AA733581257F2D80BD43EA8/?imw=5000&imh=5000&ima=fit&impolicy=Letterbox&imcolor=%23000000&letterbox=false[/img]
    [*] Imports normal-mode saves into the MOD save directory from the save selection screen
    [img]https://images.steamusercontent.com/ugc/18115726386774492493/1320C4A2DE1A98B7F6C53DB326FFDD34EB7E62C9/?imw=5000&imh=5000&ima=fit&impolicy=Letterbox&imcolor=%23000000&letterbox=false[/img]
    [*] Uses a JmcModLib settings slider to configure the total number of save slots, currently capped at 12
    [img]https://images.steamusercontent.com/ugc/12980631472390193109/2EC741B55822DA8CE5347F46D0CDC8FDB0A2B057/?imw=5000&imh=5000&ima=fit&impolicy=Letterbox&imcolor=%23000000&letterbox=false[/img]
    [*] When there are more than 3 slots, the save selection screen displays 3 slots per page
    [img]https://images.steamusercontent.com/ugc/13180653402982310399/6571BEFF06E8E540EF7C9C4385AE6E48342063A9/?imw=5000&imh=5000&ima=fit&impolicy=Letterbox&imcolor=%23000000&letterbox=false[/img]
[/list]

[h2] 3. Notes [/h2]
[list]
    [*] This MOD requires the following dependency:  
• [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3747526103] JmcModLib [/url]  
    [*] The localization content of this MOD (including the workshop page and changelog), except Chinese, is generated by ChatGPT. It currently supports all languages officially supported by the game. If you think any wording is inaccurate or would like to contribute your own translation, feel free to open an issue / PR on GitHub or contact me directly
[/list]

[h2] 4. Compatibility [/h2]
[list]
    [*] This MOD modifies the MOD menu UI, so it may conflict with other MODs that modify the same UI
    [*] This MOD uses the Harmony framework, so other MODs that conflict with Harmony may conflict with this MOD
    [*] This MOD uses reflection extensively, so it may stop working after game updates
[/list]
